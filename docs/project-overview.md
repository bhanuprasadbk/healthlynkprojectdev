# Project Overview

HealthLynk is a web application focused on provider workflows and patient-facing intake and eligibility experiences.

## Main Functional Areas

- Authentication and route protection
- Provider dashboard and operational pages
- Patient intake and eligibility flows
- Payor and CPT/HCPC related configuration screens
- Chat and assistant-oriented utility pages

## User Modes

- Public flow for patient entry and intake
- Private provider flow behind authenticated routes

## Navigation

Use the in-app docs route (`/docs`) to access project documentation pages intended for end users and stakeholders.
